# Portfolio context for Demo pages

Only Demo documents load these assets. The return link points to the work directory and its stable project ID. A URL language or palette takes precedence on entry, followed by the existing portfolio preferences. The shell listens for same-origin storage changes and keeps language switching independent of the current editor state.

The controlled vocabulary covers interface labels. Source passages, poster copy, personal drafts, quoted comments and company names keep their original text. Product code supplies the Chinese and English explanation together after calculating a result. Dispatching a `demo-insight` event with a null detail restores the initial guide. No document content or trial results are sent to a language service.

The Eval and Bundle repositories host the same shell in their own public assets. The standalone Filing Eval demo vendors it under its demo directory. Keep those assets in sync when modifying the shell.

Supported entry parameters use explicit product values: TasteRoom direction, RAG date and question, Agent case, Dinner Table budget preview, Room Notes room, Filing Eval sample (or its existing hash), Studio example, Eval sample and dimension, Bundle adoption (0–1, preview only). Only values present in the incoming link can be continued. A preview or incoming link does not grant permission to save preference rules, cast votes, or apply a commercial scenario.
