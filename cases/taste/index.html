先做出作品，再决定记住什么。

把自己的文案放进六套原创构图，保留两份候选，导出海报。整体风格与单项参数分开比较，确认后才保存有范围的偏好。

建议先试：改自己的标题，比较编辑杂志与双色印刷，留一份候选并导出；再决定是否只在日常场景记住方向。

本地原创 SVG 排版与规则模拟；无生图或模型调用

要解决的问题

用户说“喜欢”，到底喜欢的是哪一部分？

整张海报同时改变多种特征，单次选择无法说明原因。把它直接当成稳定偏好，还可能让工作和日常的需求互相干扰。

独立实现作品／偏爱双入口、六套原创构图、同文缩略图、候选、排版控制、任意风格对照、范围记忆及说明书复用。SVG 与 PNG 复用同一渲染，长期规则不随试用自动写入。

方案与取舍

喜欢一整张可以只是喜欢这件作品；只有人确认了维度和范围，才值得让下一张沿用。

一次选择，全部记住

操作最少，但把一次选择的原因推得过远。

让用户填完参数

边界清楚，却把探索审美变成配置表。

先留线索，再拆开验证

采用的做法：单变量对照、可跳过、确认范围后才写入明确规则。

把判断变成机制

  1. 每个方向要真的改变构图

    瑞士、解构、编辑杂志、包豪斯、日式留白和双色印刷使用不同几何与层级，展示同一份文案及容量提示。字号、换行和密度可微调；过密时保留内容、指出问题并暂停导出。

  2. 整体选择不偷换成参数结论

    任意选择两方向比较，依据记为整体构图；只保存方向，不推断字体、色彩或留白。参数对照才保持其他条件不变。选中、导出与保存规则是三件独立的事。

  3. 下一张能复用，也能推翻

    两份候选只存作品快照；确认过的偏好单独导出。JSON v1／旧 Markdown 说明书可再导入，先看替换项再确认，保留原场景与线索属性，且支持撤回。

验证、代价与下一步

核心检查覆盖六构图、任意对照、过期状态、说明书往返与旧草稿兼容。浏览器与导出文件验收由本轮集成记录补充；尚无真人研究证明这些维度足以描述个人审美。

六套构图提供足够的差异，也明确容量边界，没有变成任意拖拽设计工具。字体依赖系统，SVG 跨设备字形可能不同；PNG 保留当前渲染。偏好规则不是人格测量或学习准确率。

观察首次使用者能否完成自己的第一张海报，再把已确认偏好用于第二张。比较直接做作品与先探索的负担，记录过密、反悔和错误记忆，不用风格点击数代替价值。
