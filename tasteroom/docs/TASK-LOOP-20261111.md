# 同一文案，个人与工作分别记住了什么

2026-11-11，开发分支待审。没有合并到 main，也没有部署到线上。

## 这次补的任务

画布工具栏增加“个人 / 工作对照”。用当前已应用的文案、尺寸与主图，各画一张个人场景和工作场景的海报；下面列出不同参数及其依据。用户无需切换工作场景，就能检查授权规则的作用范围。

- 只使用有效、明确授权的场景规则及全局继承。未授权项目使用默认值；不把临时试用、推测或 `once_*` 条目算作长期授权。
- 两侧从同一份内容与图片独立渲染，复用原构图与图片裁切逻辑。SVG 引用独立命名，不改正文、图片或原始规则。
- 原编辑器里尚未“更新画布”的文字保留。对照展示的是当前已应用内容。
- 对照为原生只读弹层。背景编辑、切换和导出暂不可操作；关闭或 Escape 后，焦点回到入口，继续原作品。
- 打开、关闭不调用场景切换、记忆协调或保存逻辑。当前场景、临时参数、历史、撤回与本机存储均不变化。

视觉沿用现有纸面、墨色、边界及160ms弹层过渡，支持减少动态效果。桌面并置两张作品；手机缩略图并置、差异逐行阅读。没有增加生图或模型调用。

## 验证记录

原47项核心与接口测试保持，通过；增加8项纯函数测试，共55项通过。新增测试覆盖未授权、场景覆盖全局、临时与推测排除、规则有效性、输入不可变、SVG 引用与正文保真。

实际 Chrome 检查1280、768、390宽度、三种海报尺寸、键盘和减少动态效果：

- 通过真实界面分别授权瑞士与日式方向；同文同图、独立图片视口，差异与来源一致。
- 未授权两侧同默认构图；不声称默认结果代表用户偏爱。
- 打开、关闭前后，原画布、未应用输入、场景、历史、撤回和完整本机存储不变；监测到的存储写入为0。
- Escape/按钮关闭后可继续真实SVG导出；刷新仅恢复原有两条授权，不恢复临时对照。
- 没有横向溢出，没有外站请求或模型调用。
