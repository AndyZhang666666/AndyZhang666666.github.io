# TasteRoom · 偏爱实验室

独立生活审美实验：你喜欢的海报风格，不一定适合每个场景。用户很难完整描述偏好，系统也不应把两次点击当成永久规则。

## 最小体验
两轮 A/B → 生成可解释推测 → 600ms 间隔调用工具整理海报 → 打断纠偏 → 本次、全局或新场景仲裁 → 换内容验证。目标 30–45 秒完成，此为设计目标，非用户测试结论。

## 实现边界
纯 HTML/CSS 受控海报，五个正交属性；前端状态机与本地存储；显隐式记忆、置信度、来源、场景、覆盖状态；逐条操作引用记忆；暂停、单步撤回、重做；删除、锁定、迁移记忆；重置。
本地规则模式必须明示。自由文本只解析可识别的审美表达，未知输入不虚构理解。可选模型仅走同源服务端，Key 只在环境变量；公开 Pages 默认不调用模型。

## 关键裁决
- Explicit 优先于 Implicit，同级场景优先于全局；高置信推测或明确规则发生冲突必须暂停。
- 全局纠偏需要同时覆盖同维度场景规则，防止所谓全局修正实际不生效。
- 新场景保留个人审美，工作规则单独存储；仅本次例外在切场景和换内容时失效。
- 回滚指定操作后，按其余操作重新折叠状态，保留后续不相关变更；恢复操作也使用同一重算机制。
- 置信度是规则启发式权重，非模型校准概率；点击选择只产生推测，微反馈明确语句产生明确规则。
- 页面不接收或保存 API Key，localStorage 只存审美状态；输入用 textContent 或转义输出。

## 验收
两轮选择、三种仲裁、场景切换、新内容、记忆管理、撤回重做、暂停后无迟到操作、重置、损坏存储、未知文本和模型失败降级；桌面/手机无横溢，键盘可操作，减少动画偏好可用。README 公开测试命令和真实截图。

## 非目标
生图、拖拽编辑、账号、多用户、数据库、付费服务、自动发布用户内容。无用户规模、业务收益或真实模型效果宣称。
