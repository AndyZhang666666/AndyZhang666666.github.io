# TasteRoom：作品工作室精修

本轮只修改作品呈现与工作台，不增加模型服务，不修改偏好引擎、记忆授权、存储键或报告字段。原线上版保留，等待统一审阅后发布。

## 为谁、完成什么

面向已经有一段活动文案、想做出可分享海报的人。先编辑并应用文案，比较真实构图，导出当前作品；只有用户明确指定范围，才保存长期偏好。

排版桌上的纸张、校样、构图库、两个候选、双墨套印是这个工具的工作语言。界面沿用纸白、灰绿工具面、深绿色主操作；作品里的朱红、墨蓝、黄赭由各自构图承担。主画布是唯一视觉中心。

| 原先 | 本轮 | 选择原因 |
| --- | --- | --- |
| 六个顶部动作与侧栏重复构图入口 | 一个同文构图库，PNG主出口，SVG在格式菜单 | 选择构图、编辑、导出各有一个清楚位置 |
| 展开图库推动整页 | 原生对话框与准确焦点返回 | 切换构图不打断正在做的作品 |
| 文案草稿只在编辑区提示 | 画布旁常驻应用状态；导出时明确二选一 | 导出的究竟是哪份内容需要可见 |
| 编辑栏、画布、候选与记忆争主位 | 280px编辑栏、主画布、下方候选；记忆默认收起 | 创作与长期授权是不同任务 |
| 手机把全部编辑和画布连续堆叠 | 同一DOM在“画布与对照／编辑内容”间切换 | 不丢字段、保留草稿，也不用反复长距离滚动 |
| 画布尺寸改变后共用近似版位 | 六种方向×三种尺寸分别重排标题、图片和信息 | 不是把竖版压扁成为横版 |

## 共同渲染、不同构图

六种方向继续使用既有ID：`swiss / deconstructed / editorial / bauhaus / japanese / risograph`。标题、主图和活动信息有可计算的工作区域，三种实际输出尺寸不变。瑞士强调网格与两种基础形；解构采用有限倾斜与错位；编辑方向有刊物注释和字体层次；包豪斯让几何主视觉与信息分工；日式保留可读字重与负空间；双色只对标题与局部图形使用小幅套印，正文没有重影。

所有当前预览、构图库、候选、场景对照、SVG与PNG仍使用`posterSvg`同一入口。旧候选的输入资料、图片和风格ID原样读取，以精修后的版位显示，没有数据迁移。

可读性设置了下限；容量超出时保留全文与草稿并阻止导出，不无限缩小或截掉用户文字。主图仍只处理本机PNG/JPG/WebP；填满/完整、焦点、候选与恢复继续沿用原功能。

## 交互边界

- 输入保存草稿，不自动应用；“更新画布”才将文案写入当前作品。
- 未应用编辑时可选择“导出当前画布”或“先更新再导出”；后者仍经过原校验。
- 构图切换、临时采用、导出与场景对照均不授权长期偏好。记忆保存仍展示范围和替换影响，并可撤回。
- 面板开合、图库、手机工作面和导出选择都属于临时UI状态，不写入偏好或作品数据。
- 有效控制至少44px触达；减少动态效果时取消画布转场。动画不驱动任何业务状态。
- 所有改动过的原生依赖链使用`20261112-craft1`版本标识，避免旧缓存混载。
