# 从换风格到完成作品

2026-11-01；开发分支 `feat/product-depth-20261101`。本轮尚未发布，浏览器验收由官网集成流程另行记录。

这个版本让用户完成两件事：带自己的文案制作海报；在具体比较中形成可复用、可撤回的偏好。两个入口共用同一份文案、画布和本机规则。没有登录、在线生图或模型依赖。

## 完成一张作品

“做一张作品”默认打开编辑画布。类别、标题、副文案、落款可以全部替换；活动起点是原创示例，不是用户研究结果。标题与副文案最多四行，原始文字不被静默截断。字号、自动／手动换行与密度属于可试用控制。

六个命名方向拥有各自的原创几何结构：瑞士的网格层级、解构的错位叠压、编辑杂志的刊物分栏、包豪斯的非对称形体、日式的负空间、双色印刷的套印构成。同一份内容进入同一个 SVG 渲染器，真实缩略图不是另画的宣传图。自由参数保留在高级入口。

每套构图显示容量与适用提示。内容过密或接近落款区域时，保留文字并提示调整；导出停用，可重新平衡换行、缩小标题或回到编辑。画面装饰在内容较多时退让，不盖住文字。排版宽度是本地确定性估计，不是浏览器字体测量或专业印前校样。

候选区最多保存两份作品快照；切换候选恢复文案、参数和排版设置，不把作品偏好写进长期规则。满位后先移除一份；存储失败时仍可在本页使用。

## 比较与记忆

“探索我的偏爱”先提供两轮当前内容的实际画布选择。选择形成临时画布，不直接授权长期规则，随后可进入任意两种命名方向的对照。

- 整体构图比较包含多个视觉因素，依据记录为 `whole-direction`，只保存所选 `artDirection`，不推断字体、色彩、留白等维度。
- 参数对照记录为 `single-variable`，同一内容、同一其他参数，仅变化一个枚举维度。
- 选 A/B 只是临时预览。用户可以直接导出，再明确选择仅本次、当前场景或全局保存。换内容、参数、排版设置、场景或规则后，旧对照失效。
- 明确规则与待验证线索仍分开，场景继承与冲突仲裁沿用原状态机。任何风格名都不代表人格判断。

## 偏好说明书的下一次使用

说明书提供 Markdown 与可复用 JSON 导出。读取旧 `tasteroom-style-brief-v1` JSON，以及原工具导出的结构化 Markdown；文件上限 256 KB。

解析先校验格式、枚举、场景、规则类别与重复维度。界面列出每条将导入的规则和被替换的同场景旧规则；确认后才合并，其他场景规则和文案保持原样。待验证线索不会被升级成明确规则。取消或坏文件不改当前材料，确认可用“撤回上次记忆操作”恢复。

SVG／PNG 只包含作品内容和画布参数，不带私人反馈、记忆依据或候选历史。SVG 与 PNG 来自同一份 SVG，PNG 在异步等待前捕获点击时的画布。PNG 为 900×1200；SVG 在不同电脑上可能使用不同系统字体，跨设备精确字形不在本轮保证范围。
