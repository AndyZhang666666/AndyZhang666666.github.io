# 第二轮：记住什么，也需要本人授权

## 核心判断

喜欢整张海报是混合信号，不代表喜欢每个参数。两轮初选保留为待验证线索；不能继续靠 UI 百分比把它包装成确定结论。新流程提供单变量对照，保持内容和四个参数固定，让用户验证第五个，并明确记忆范围。

对照不能证明永恒偏好，更不是统计意义的因果实验。它只比整图点击提供更明确的、可撤回的本人反馈。

## 状态与授权

- 生成对照不写记忆；A/B 选择仅是待确认候选；“都不选”和关闭不推断偏好。
- 仅本次不保存；当前场景只改该场景；全局修正明确覆盖这一维旧活跃规则。全局视图的“当前场景”按钮禁用，避免把继承影响称为私人修改。
- 写入前检查场景、内容、画布与记忆指纹，并校验两张确实只改变一项；过期或被改动的对照拒绝。
- 其他四维不跟着被选中的海报一起写入。证据记下被试维度、内容序号、两组参数和选择。
- 记忆删除、锁定、迁移可撤回上一次；画布步骤回滚与持久规则管理分开，不能用视觉撤回暗中改变长期规则。
- 多维或未支持否定表达提示未理解，可改用明确的参数控件。公开版本没有任意自然语言能力。

## 可带走产物

说明书列当前画布和所有场景中的活跃持久规则，分开标记明确规则与线索；可能包含本人输入的反馈，下载时提示自行保管。SVG 只含当前参数、场景与样例内容，**不夹带反馈或记忆库**。它是 900×1200 的矢量重排版，不是像素一致的截图，也不是模型生成图片。

## 视觉取舍

保持原工作纸框架，主角是真正变化的海报，不加照片、霓虹或假分析看板。对照区是可展开工作页，轨迹默认折叠；桌面右栏不被左栏拖成长空白，平板采用单列主任务加双列辅助区，手机保留画布/记忆切换。主要说明与操作增大字号，海报内的微型排版属于被比较的作品。

## 本轮验证与下一步

25 项 Node 测试覆盖原状态机、受控对照、授权范围、失效、导出转义/数据最小化、长历史保留以及可选模型契约。真实 Chrome 跑过新旧完整流程和四种宽度。模型契约只用本机假服务，没有启用真实模型。

下一步先用少量自愿试用者验证：是否理解线索与规则、是否能预测场景继承、是否敢用“都不选”。不以多建几条记忆当产品价值，更不填造留存或准确率。
