技术详情与运行边界

三个工具：查询工单、提交变更、查询原操作状态。判断依据是最终数据库状态和事件；不展示模型隐藏思维链。

基础版

查询 → 经批准提交 → 返回结果。发生工具错误就停止并报告；没有自动查询恢复。

加固版

先查权限；查询最多 3 次。回执未知先查原操作，版本变化后重新查询与确认，结束前核对数据。

两版使用相同初始工单、故障和服务端鉴权。正常与重复提交案例可以同时通过。示例中的差异来自确定性程序策略，不代表模型能力或提升比例。

三种来源分别标注：真实模型运行需要本地配置；真实记录回放仅播放模型留档；示例演示不是模型结果。本地程序测试实际写入 SQLite，仍不属于真实模型运行。

耗时为记录的总经过时间（含人工等待），播放速度不是执行耗时。用量没有记录时显示「未知」。
