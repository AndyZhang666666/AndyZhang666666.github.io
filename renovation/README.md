# 安心装修 · 家具选购手记

[打开 Demo](https://andyzhang666666.github.io/renovation/) · [迭代记录](CHANGELOG.md)

这个项目起于一个家庭需求。长辈在家具店看中了款式，回到家却需要从头解释摆在哪里、谁量过、报价包不包上楼。家庭版的讨论从手机提问和装修看板，逐步转向商品候选、下单前核对、点图选家具与家庭交接。公开版选择其中一条可以独立完成的路径，使用原创示意图和虚构报价。

## 体验

1. 点平面图的沙发或餐桌，再选一个报价。展示所需尺寸和标价。
2. 输入可用尺寸和该款送装费用，也可使用明确标记的示例回复。尺寸按同一位置共享，商家费用按商品隔离。
3. 查看余量、超出量或待确认项。只有确认送装费后才得出到家合计；未知费用和已确认的零元有不同结果。
4. 保存一张交接单，更改条件后可对照上次保存的版本；也可导出当前条件的文本交接单。

## 离线与数据

下载网页底部的离线 HTML，在启用 JavaScript 的浏览器打开即可。HTML 内含全部样式、示意图、计算逻辑和示例，无外部字体、图片、依赖、账号或 API。浏览器打开网页后即可断网操作。记录使用当前浏览器的 localStorage；存储受限时可导出文本。本地文件与在线版的存储空间由浏览器分别管理。

公开版使用确定性规则，按摆位净尺寸做单一方向的初筛；搬入路线、现场安装与真实商家报价需另行确认。家庭版的照片、图纸、聊天、服务地址与凭据未用作公开素材。
