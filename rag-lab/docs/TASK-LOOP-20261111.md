# 草稿数字核对与同题条件变化

状态：开发分支本地实现及验证。未合并主分支，未部署；没有真实模型或真人使用效果声明。

自己的资料工作区沿用原本的导入、检索、勾选引用、草稿与导出路径。草稿上方增加实时提示：仅比较草稿中的阿拉伯数字及天／元／次／台／小时，与**当前勾选段落的引文文字**。全角数字、数字与单位之间的空白、等值小数作一致规范化；不把分隔的两个数字拼成一个数字，也不通过浮点转换丢失大整数精度。每个未匹配的数字分别提醒。空草稿、未选依据、无支持单位、旧检索各有明确说明。

提示不阻止编辑、复制或导出；原有“资料或条件变化后须重查”的导出保护继续生效。JSON与Markdown会带走数字提示和引用范围提醒，避免把有提示的草稿导出成“已验证答复”。文字匹配只说明所选引文出现了数值，不验证语义、实际适用性或事实真假。

引用范围提醒复用冻结引擎可识别的设备主题与规则字段。只有同主题、同规则及相同可识别主体语境的数值／规定或生效区间不同，才提示写明适用对象与期间；不同设备、不同规则、明确不同区域／公司／机型及仅共用单位的文本不并组。范围外条款不作通用冲突判断。该提醒不决定哪条优先，也不代替用户核对。

内置任务只比较紧接的上一次已完成运行；问题、任务、事实、运行方式或生成方式不同均不显示差异。仅日期、快照或身份条件变化后重查，才说明前后条件、可用引文编号／版本及结果是否变化。不向新记录嵌入完整旧运行。身份、管理凭据或运行范围切换时，先清除旧结果、引用、技术详情、隐藏通知及导出指针；比较锚只保留安全条件。受限历史及其草稿仍留在原本五次内存历史内，按当前会话范围过滤呈现，重新取得相同管理会话后可核对；不改个人工作区的本机存储契约。
