状态：开发分支，本地审阅；没有合并或部署。本轮没有模型调用。

## 解决的问题

原版进入任务后仍被完整案例目录占据视野；自有资料尚未导入时已出现整屏空答复；引用定位需要离开当前阅读位置；勾选和插入草稿缺少各自反馈。

- 六个边界案例首次仍可见，运行后折叠为场景入口。日期、身份、快照和待重查提示保持在问题旁。未采用的相近资料默认收起并显示数量，避免排除列表撑高主要阅读面。
- 桌面采用问题、回答、来源并置的阅读桌。辅助技术详情退到次级入口，没有改成通用聊天框。
- 自有资料的空状态先完成导入；已有文档显示版本核对入口，保留原文预览和确认。手机以资料/依据/答复单工作面切换，保留内容与阅读位置。
- 引用点击后就地展开原文、版本和有效期间；手机全屏核对并返回原引用。完整来源卡始终可达。
- 采用依据显示数量，但不写答复。加入草稿明确插入了原文。数字与适用条件提示仍为非阻断核查线索。

## 授权及数据边界

没有修改 `engine.mjs`、`workspace.mjs`、固定资料、报告结构、索引规则或存储键。UI面板状态只在当前页面保留。

引用检查器仅接收当前允许显示的片段；条件、身份、运行范围、任务或工作区变化时同步清空内容、关闭弹层并解除定位监听，随后才进行下一次呈现。不会使用退出动画保留旧引用。旧回答的待重查规则继续使用原逻辑。

定位依赖为 MIT 的 `@floating-ui/dom 1.8.0`，通过开发工具 `esbuild 0.28.2` 打包成自托管 ESM。使用 `npm ci && npm run vendor:floating` 可复现；资产附原许可。预览及API只额外允许具体模块、样式与许可文件，未开放 `node_modules` 或服务器目录。
