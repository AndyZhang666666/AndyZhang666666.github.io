# 交互与 AI 边界
证据：docs/PRD.md；使用 product-design-and-ux 的 AI interaction / task-state / interface contract。以下是设计与实现约定，不是真人研究结果。

目标：访客从预设问题开始，查看与当前授权范围、业务日期和快照绑定的回答，点击来源，改变条件后重新运行。问答不产生业务操作。

| 状态 | 显示内容 | 控制与恢复 | 验收 |
|---|---|---|---|
| 初始 | 默认问题、固定日期、示例标签、模式边界 | 可直接查找 | 不要求密钥 |
| 处理中 | 正在查找/生成，保留问题条件 | 提交按钮暂时禁用；失败可重试 | 防止重复提交 |
| 有依据 | 回答、结论所用版本、段落引用 | 点击引用把焦点移至来源 | 来源属于该次快照 |
| 无答案 | 未找到适用依据以及下一步 | 修改问题或条件 | 不把相似无关文字当规则 |
| 需要澄清 | 设备或问题范围不明确 | 补充具体设备或一次一个问题 | 不机械猜设备 |
| 冲突 | 同等生效依据的不同规定 | 查看双方，联系虚构行政负责人确认 | 不任意挑较新文本 |
| 权限不足/范围缺失 | 当前可访问范围没有足够依据 | 本地使用独立管理凭据；公开示例不含管理原文 | API 不泄露标题/片段，拒绝角色篡改 |
| 条件已改 | 原回答保持原日期/版本，提示需重跑 | 再次查找；历史记录可恢复 | 不把新条件套到旧回答 |
| API/模型失败 | 失败阶段、可重试；未配置单独说明 | 保留问题和条件 | 不回退并伪装模型成功 |

模型只生成受限 JSON，不做权限或版本判断，不执行工具。上下文是已授权、适用的实际召回段落；检索文本作为不可信资料。校验引用存在、引文逐字匹配；已识别业务事实再核对单位/数值。通过不代表所有自由文本语义已获证明，真实模型固定题必须另行复核。

普通会话通过本地 API 获取临时员工凭据，管理会话仅由服务端配置的独立 token 识别；不接受 body.role。公开站自由切换身份仅解释虚构场景，不是生产鉴权。公开包不包含管理资料；公开 GitHub 源码中的虚构管理测试数据并非机密存储。

窄屏/文本扩展：控件换行，阅读栏纵向排列，长编号断行；来源焦点与引用相连。键盘原生 button/select/details，无拖拽前提。断网保留输入，错误可重试。历史只留内存且最多五次；API 记录有会话隔离、数量与时效限制，导出做脱敏，不持久保存凭据。
