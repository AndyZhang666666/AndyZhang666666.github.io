# 界面约定
继承官网默认 frost 的象牙纸、墨色和朱红，用于一个 Operate/Read 工作页面。用户已明确要求直接实现最小版，因此依据 PRD 决定布局，不引入额外选稿环节。impeccable context 因缓存写权限失败；直接读取现有代码、技能参考和官网样式。

主要对象是回答及其可用依据。顶部紧凑导航与运行模式；左侧问题和条件，下方阅读区以回答、来源两栏展开。回答中的引用按钮直接定位来源段落，来源显示文档版本、日期和适用身份。技术详情折叠，不用装饰性总分。手机按提问、回答、来源顺序排列。

颜色：纸 #f5f2eb、正文 #282a27、次要文字 #626159、动作 #ad3617、来源选中底 #eee7db；输入白底，关键边线 #cdc5b7。系统中文字体优先，标题和控件采用同一字体；数字等宽。正文 16–17px，行距 1.7；主标题 30px。动效仅在来源定位时提供短暂底色反馈，减少动效时关闭。无外部字体和图像依赖。
