## 四项交付内容

### Eval：评价复核与改稿有联系

保留五维原分、标准、引用定位和历史样本；新增无模型的个人文稿工作区。原稿不可静默改写，修改稿可以关联处理项；人工观察、模型结果和处理状态分别保存。片段用途的不适用理由进入单篇与完整文稿报告，且与版本自己的不同意见分开。

自带评价可粘贴单个JSON代码块；原始与规范化输入都留存。快捷示例明确标为合成练习，不能当成模型效果。校准小结列支持、存疑和需上下文的数量及维度。Markdown包含已有中文释义。

原始材料仍限1MB；自家报告的额外信封有单独有界预算与内容绑定验证。真实400KB材料导出为超过1MB的报告后，已在干净浏览器重新上传并导出。新编辑超过20,000字符时保留全文、就地提示、阻止无效新任务；旧大报告继续可读。

源码：[`66a13b4`](https://github.com/AndyZhang666666/llm-output-eval/commit/66a13b4551a9cccaeafb7d8ab3a308c808ec99c8)。[项目更新](https://github.com/AndyZhang666666/llm-output-eval/blob/feat/eval-product-depth-20261109/docs/PRODUCT-DEPTH-20261109.md) · [报告兼容验证](https://github.com/AndyZhang666666/llm-output-eval/blob/feat/eval-product-depth-20261109/docs/REPORT-ENVELOPE-20261109.md)。

### 偏爱：完成作品，再决定记住什么

六种独立构图均支持900×1200、1080×1080、1600×900三尺寸重排。新增活动日期、地点与行动说明，本机图片、适合／填满和焦点；容量问题明确指出，不删除原文来强行导出。

两个候选保存完整作品状态；构图比较、单变量比较、临时采用和长期授权分开。成因条说明当前方向与临时改动；恢复场景已记方向不写入记忆。图片保存在IndexedDB，PNG与SVG来自同一渲染状态。

实现原提交 `6f57a19 → 7ccd4ef → 956a599`，已按真实来源合入官网开发分支：`24ba3d4 → f47b10b → 8bec512`。没有拆新仓丢掉历史。[模块说明](../tasteroom/docs/PRODUCT-DEPTH-20261109.md) · [实际导出及浏览器记录](../tasteroom/docs/evidence/product-depth-20261109/)。

### Bundle：从假设到验证计划

新增手工计数和CSV基线。按订单的商品出现关系去重；不同参考价先展示分布并要求确认。数量、实付、退款等未建模字段不会自动解释。实际覆盖订单与每100单归一账本分开。

三份方案快照与条件地图共用原引擎。新增最高可承受折扣与经营诊断；预演不自动采用。验证计划冻结当时条件，回填试验／对照观察后，先预览差异，再明确复制为新工作假设；原方案、原CSV与原计划保留。

源码：[`4cab0dc`](https://github.com/AndyZhang666666/bundle-lab/commit/4cab0dc75fa70df970c016b642d294fbb8a33dde)。[项目更新与限制](https://github.com/AndyZhang666666/bundle-lab/blob/feat/bundle-product-depth-20261109/docs/PRODUCT-DEPTH-20261109.md)。原 `lib/simulate.js` 与本批基线逐字相同。

### RAG：自己的资料也能完成任务

修复遗失／借期碰撞，补充计日方式与同义词。六个快捷边界与12类任务共用检索及规则；补充条款同样经过角色、日期和快照筛选。原12份公开语料内容不变，另12份原创任务资料独立提供，不把管理资料放入公开包。

自己的TXT、Markdown、文字PDF在浏览器解析。元数据未知的来源仍可检索，不被已知版本静默淘汰；它们不能直接形成适用结论。同段多条受支持规则有不同数值时保留冲突。扫描／损坏／加密或部分无字页面有对应提示，原资料与草稿不被失败导入覆盖。

选择引文、人工草稿、待确认项、Markdown和JSON备份可往返。旧草稿沿用会在界面及导出中明确标记。损坏存储暂停写入，允许下载原始值及明确重建；清空或恢复会取消在途导入的应用。切离管理员清空所有旧敏感展示。示例资源失败时，自己的资料仍可独立工作。

本机API增加能力查询、条件任务和会话所属工作区／草稿／导出；模型默认关闭，前端不能用参数开启。自托管PDF.js及字体／CMap保留各自许可证。没有付费模型调用。

核心提交 `0503cf3 → 99abb4d → 96ea305 → fdf1eb8`。[实现与API](../rag-lab/docs/PRODUCT-DEPTH-20261109.md) · [完整本轮证据](../rag-lab/evidence/product-depth-20261109/)。
