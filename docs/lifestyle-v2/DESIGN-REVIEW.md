# 两个工作屏的视觉复查

2026-10-24。使用 design-taste-frontend 的 app-screen 流程与 product-design-and-ux 的状态/授权合同。不将照片数、宣传页动效或奖项评分作为工作屏目标；以下为作者自查，不是独立设计评审或无障碍认证。

## 方向与对象

- 随便局：framed-sheet，seed 1837227683。问题是“当前这餐是否已被每位成员接受，以及无交集时能怎样继续”。对象是 3–5 位虚构朋友、四个初始虚构餐厅（最多八个）、人均元、条件、草稿、同版表态。当前状态与公共决定单是识别元素，墨色主操作、浅鼠尾草纸面，保留原系统字体。
- 偏爱实验室：framed-sheet，seed 29588037。问题是“这是哪一项偏爱、允许记在哪里”。对象是五个受控风格枚举、三个虚构海报内容、全局/日常/工作规则、单项对照、仲裁与导出。保留自托管 IBM Plex Sans 界面字体，以真实可变海报而非装饰插图作为识别元素。
- 没有新增线上分析、服务端或外部素材。所有人物、餐厅与活动名称均为演示数据；未来真实接入时必须替换并核实，不能把现在的模拟数量当用户量。

## 两轮复查中实际修过的三处

1. 随便局初始页原来有两个重复开始按钮与空泛说明。现在只保留上方主入口，下方用三位虚构朋友的不同顾虑说明问题；手机逐条排，而不是挤成三列。
2. 偏爱实验室展开对照后，右侧记忆栏被左栏拖成超过一屏的空白。改为自然高度，宽屏可随滚动保留记忆依据，轨迹默认折叠。
3. 原平板两列同时放 A/B，作品太窄。改成完整主任务在前，辅助区双列在后；手机维持画布/记忆切换。对照微型排版字号下限 11px，手机给足高度，不靠裁掉副标题节省空间。

## 七项工作屏复查

| 问题 | 随便局 | 偏爱实验室 |
|---|---|---|
| 最大块是否回答当前任务 | 主状态明确收集中/无交集/可行/共同决定，下面是条件与候选 | 海报为主角，对照区只比较一个维度，确认范围独立于选择 |
| 边缘、空白与高度 | 内容等宽对齐；表单和结果按内容自然高度，过程记录折叠 | 辅助栏不拉伸；大留白海报是被试变量，而非布局缺失 |
| 颜色是否有意义 | 暖红只用于冲突，绿色用于通过与决定，主按钮为墨色 | 海报配色是实际参数，界面保持中性绿；不因主题参数改变界面含义 |
| 数字能否对齐与重算 | 人数、票数、版本、人均都从状态计算；¥40→¥85 明示增加 ¥45 | 记忆数按当前场景活跃规则计算；不显示未经校准的准确率 |
| 零与未知是否诚实 | 未知价格不是零，相关信息未知不进入可行集；零票就是零票 | 零规则有说明；不支持的文本不伪装理解；两张都不选不增加记忆 |
| 图形、说明与碰撞 | 无伪统计图；候选的价格、状态与按钮独立，决定单不叠字 | 同内容同其余参数由同一画布克隆生成；手机海报留足高度，副标题不删 |
| 手机是否仍能做完 | 单列条件/候选，表态后可切下一位；角色栏不遮内容 | 画布/记忆两面切换，范围选项堆叠，主要按钮 44px；无需横滑 |

## 工具证据与边界

- 最终冷启动 inspect：随便局 0 FAIL / 0 WARN；偏爱实验室 0 FAIL / 1 WARN。唯一提醒是书刊卡片内部 74px 空白；这是“留白”选项本身，被比较对象需要保留，非空白侧栏。
- 源码 lint 0 FAIL / 0 WARN；桌面 1440、平板 768、手机 390 的 fold 和整页截图均查看；运行态、无交集、共同决定、对照与手机记忆面板另有实际浏览器截图。
- 新旧流程检查含 360px 窄屏，未发现横向页面溢出或页面脚本异常；实际下载 Markdown/TXT/SVG 并核对内容。长页截图在连续切宽后出现过拼接异常，独立新上下文复拍并检查 DOM，未出现重复页面；测试截图前增加两帧布局等待。
- 当前是完整本地交互作品，不是“真实多人 / 真人使用已验证 / 获设计奖 / 全面 WCAG 合规”。后续更大的提升应来自真实试用与服务端，而不是继续增加装饰。
