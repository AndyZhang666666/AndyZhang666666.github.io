## 四项改变

- **偏爱实验室**：作品居中、280px编辑栏、单一六构图库、收起的记忆检查器；六种风格分别适配三种尺寸。未应用编辑时可明确选择导出当前画布或先更新，候选与长期授权独立。
- **Eval Lab**：统一材料选择、证据三栏、邻近量表及往返入口、单一处理清单和报告格式菜单。手机定位原文后返回同条评语，保留维度、备注、引用与焦点。
- **Bundle Lab**：精确输入和键盘滑杆、可核对的贡献—让利—净收益账本、原值收益桥接、真实行列矩阵、独立预演与冻结方案。原模型与草稿保护保持。
- **可信RAG**：问题、答复、来源并置；空状态先导入资料；点击引用就近核对版本和生效期；采用与插入分别反馈；条件失效立即清理旧引用，手机采用单工作面。

官网同步四精选的说明、当前工具入口与真实界面展示。18项作品及首屏、关于AI、经历、教育、主题、背景、毛玻璃和原动效保持。
