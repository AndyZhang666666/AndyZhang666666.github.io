# 本地界面复核 · 2026-10-27

使用 `impeccable` 的界面打磨流程和 `design-taste-frontend` 的应用检查、实图复核。官网设计是用户指定的固定约束，未根据通用审美规则删减它的玻璃、背景、特效、主题或互动。

## 改前与改后

原版五个 Demo 的浏览器实图在 `.taste-skill/demos-before/`；更新版三种宽度及操作实图在 `.taste-skill/delivery/`。`review.html` 可在隔离端口的原版和更新版之间切换，不覆盖原文件。

Eval 原先的小雷达在窄列中标签拥挤，分数卡、解释和操作容易挤成同级信息。改后用真实五维数值的水平量尺、从低分开始的校样行，原文与人工复核组成同一阅读列。红色用于低分与引用定位，清楚区分原评分和人的判断。它仍是信息密集的业务工具；手机需要纵向阅读，没有删掉说明来换取短页面。

偏爱实验室原先把参数、操作、海报和记忆都放在相似的浅色容器里。改后把海报工作区作为主体，方向选择在前，编辑和参数按需展开，记忆作为旁栏；手机可切换画布与记忆。海报有两种独立的原创构图，实际字体、内容、留白、对齐、色彩和装饰参与渲染，导出使用同一当前参数。一次试用不是持久授权。

## 检查器结果与判断

两套重点界面在 1440/768/390px 均为 **0 FAIL**。已修复窄屏导航贴边、Safety 副标签对比度不足、页面级 `data-ui` 误用、过重海报投影以及 10px 工具记录等问题。

剩余警告如实记录：

- Eval 深色横线：只用于原文、结果和复核区域的起点，是用户指定瑞士排版的分区语言；没有给所有卡片加深色四边框。
- 两个应用的列高不齐：原文/海报与评分/记忆是不同工作对象，旁栏在桌面保持可见、各自滚动；不是需等高的一排营销卡片。不为消除警告填充空内容。
- 偏爱实验室部分 11–12px 辅助标签、日志和解释：正文与主要决策文字维持 13–22px，手机最小文字为 11px。属于密集操作区的次级信息，已按实图检查，无裁切。
- 海报淡纸色：是可导出设计作品的内容色，不是应用整体配色。工作台本身为中性灰绿。
- Eval 最后一项导航曾距手机边缘约14px；减少移动端导航间隔后，该警告已消除。最终为 Eval 2 项 WARN、偏爱实验室 3 项 WARN，均为上述有意保留的构图/辅助信息选择。

## 有限动效

按钮在按下和焦点时反馈；实际构图变化时海报 240ms 过渡，评测运行改变时结果区 220ms 过渡，引句定位使用一次高亮。没有把静态页面隐藏到动画结束，没有循环移动的阅读背景。减少动效模式已实际验证为关闭这两类脚本动画。
