## 需要观察的边界

- RAG：无引用、没有数值和无法匹配的单位分别说明。选中不同日期资料只是条件线索，不直接认定矛盾；切身份后只比较当前获准展示的信息。
- Eval：原始均分与参考均分并列且来源明确；单次记录不冒充稳定性评估。处理清单与引用只写入待讨论的校准备忘，不改标准。长文本采用有界对照，仍保留完整原文。
- Bundle：预设只是触达假设。默认可乐与鸡腿饭模型，每100个覆盖订单，100%/50%/15%的增量毛利分别约为−49.51/−1.70/+31.76元；15%仍有约14.34元已有顾客让利。三个快照满位需要先管理，不覆盖。观察按冻结计划核对，不跟随当前滑杆漂移。
- Taste：使用已应用内容而非尚未更新的编辑草稿；无授权时展示默认值。图片和文字同源，预览不写临时规则或记忆。
