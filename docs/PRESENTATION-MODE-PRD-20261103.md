# 官网 90 秒投屏模式

状态：本地候选，未推送、未合并、未部署。基线为正式版 `b3c192c8d9dc163024168cfdf913aff1d43df0bf`，包含最近删除精选区中英文说明及上一轮 Demo 视觉更新。

## 目标与范围

面试或屏幕分享时，快速进入四个精选作品的可操作展示。放大作品选择、问题、真实预览与完整工具入口，收起简历长文及次要链接。90秒是展示场景名称，不是已验证的完成时间；没有倒计时、自动轮播或强制跳页。

正常浏览不改个人资料、原文案、色系、背景、主题、作品、筛选、简历或已有交互。唯一可见新增是顶部的投屏入口。模式继承当前语言和主题；结束后原导航及主题选择恢复。

不修改 Eval、偏爱、Bundle、通勤的业务能力、数据、评分或计算模型。不增加跨工具导航、体验向导或说明抽屉；这些由原 Demo 任务负责。未新增真实用户、模型效果、业务收益或设计奖项声明。

## 进入、操作与退出

1. 顶部“90秒投屏”按钮支持鼠标、触摸、Enter 和空格。未成功加载增强脚本时入口隐藏，普通官网仍可阅读和使用。
2. 进入时保存本次页面内的滚动位置、选中作品与焦点。保留真实标签和预览节点及事件，避免复制后产生两套试用状态。焦点移到当前作品标签。
3. 四个标签沿用原有点击、方向键和 Home/End 行为。当前问题、来源标识、试用反馈、完整 Demo 入口保留；顶部高光随作品切换。
4. “退出投屏”或 Escape 返回原位置、原选中作品和入口焦点。投屏期间对预览的试用不被清空；其他作品筛选、展开状态和个人资料没有被重写。
5. 投屏仅切换视图。普通默认页面不自动进入，不记住投屏偏好，不写 localStorage、sessionStorage 或资料库。

## URL 与浏览器行为

- UI进入：在现有URL上增加 `present=1`，保留其他查询参数、锚点及 `history.state`，新增一个浏览历史项。
- UI退出：对本页创建的模式项执行后退；浏览器后退同样退出，前进可重新进入。不额外制造伪浏览记录。
- 直接打开 `/?present=1#selected`：进入模式；退出只移除本参数并回到该普通锚点，无锚点则回到页首，不把用户送往不相关的上一个网站。
- 刷新模式链接：保留模式，按原工具的首次加载规则初始化预览。未保存的首页试用不承诺跨刷新恢复；不额外保存个人数据。
- 若浏览到另一个普通锚点，先退出展示并到达该章节。进入前已有的参数及锚点不被替换成投屏专用默认值。
- 重复进入/退出：每次重新捕获当前位置，取消尚未执行的滚动恢复帧，防止快速操作拉回旧位置。

## 适配与无障碍

- 桌面放大原有左侧作品卡和右侧工作面；手机保留两列作品标签，工作面纵向阅读，不产生整页横向滚动或双层页面滚动。
- 退出按钮始终在顶部，最小44px触摸区域；减少动态效果下取消新增入场与位移。没有自动计时或自动切换。
- 普通长页在投屏期间 `display:none`，不能进入键盘焦点；投屏不是模态弹窗，不额外锁死Tab。顶部高光、退出及预览原有控件均可达。
- 模式内提供可见主标题、作品选中状态与开启/结束通知。新标签页高光入口有明确的无障碍名称。
- 原语言和四主题的数据及入口保留。进入前选择主题，模式继承，退出恢复；不重复创建主题偏好键。

高光案例补充要求：图片加载前后占位应一致；锚点标题在固定导航之后可见，并检查冷暖加载、刷新及手机宽度。此次独立复验的原因和最小修复见[高光修正报告](PRESENTATION-ANCHOR-FOLLOWUP-20261103.md)。

## 异常和恢复

| 状态 | 行为 |
| --- | --- |
| 增强模块无法加载 / 模板不兼容 | 不显示投屏入口，保持完整普通官网，不留下无法操作的开关 |
| 原预览按需模块加载失败 | 沿用原预览说明与完整工具链接；退出仍可用 |
| 已有原生弹窗打开 | Escape优先交由原弹窗，不穿透退出模式 |
| 原焦点节点已被其他功能移除 | 回退到投屏入口，不聚焦已隐藏节点 |
| 直接模式链接退出 | 仅替换当前URL参数并还原页面，不擅自离站 |
| 其他查询参数或同名多值参数 | 逐项保留；只管理独立的 `present` 参数 |
