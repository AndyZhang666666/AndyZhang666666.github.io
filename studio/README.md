# 三个可带走结果的产品实验

在仓库根目录双击 [studio-preview.command](../studio-preview.command)，打开[新旧版对照](http://127.0.0.1:8971/studio-review.html)。本轮候选基于官网提交 `f1677dc`。新旧对照使用两个本地端口。启动器从 Git 中提取固定版本作对照，之后修改其他工作目录也不会改变底稿。单独检出此仓库时也可以在根目录运行 `node scripts/preview.mjs`，通过 8860 端口使用候选版及三个工具。

| 作品 | 可以动手做什么 | 输出 |
|---|---|---|
| [一道菜，三种拼法](menu/) | 在原创菜单中对比原词、别名和扩展召回，检查 18 条标注查询，也可录入自己的菜品或为已有菜品补别名。 | 每条查询的目标菜、两套排序、规则和完整菜单，JSON 格式。 |
| [改一场戏](script/) | 编辑五场示例剧本的揭晓位置，也可带入自己的角色、事实和场次。标出知情对白后，逐句决定删掉、改成猜测或提前交代线索，支持撤回。 | 修订后的完整剧本、待处理对白和修改记录，Markdown 格式。 |
| [开拍前，这批生成要花多少？](credits/) | 调整镜头数、单价、团队余额、成员限额和工作日。确认报价后逐镜头成功、失败、取消或重试。已预留的批次保留原始报价。 | 生成前的报价，以及含负责人、逐笔预留、扣款、退款与过期积分的 JSON 账本。 |

三个实验使用原创或自定义材料，在浏览器中运行，文件由用户手动导出。菜单标注用于比较本组固定查询，制作积分使用示例单位，剧本工具只追踪作者标记的知情对白。对应的简历和工作经历有独立入口。

官网首页的人像下方可以打开三张纸签。进入「90 秒投屏」，选择 AI 产品、策略产品或增长商业化后，用上一幕、下一幕或左右方向键放映。Escape 返回原位置。学术区域的控件分别演示姿态反馈和盘口深度，数据用于说明交互机制。

在根目录运行 `node scripts/test-studio.mjs` 核对规则、账目与索引。启动本地预览后，`scripts/review-studio-browser.mjs` 可以使用 Playwright 与 Chrome 验证实际操作和下载。环境变量 `STUDIO_CAPTURE` 指定截图目录，`PLAYWRIGHT_MODULE` 可指定现有 Playwright 安装。
